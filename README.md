# 🏠 Chuka University Hostel Management System

A complete hostel booking system for Chuka University students.

## 🌐 Live Website
**URL:** https://jeyfolix.github.io/hostel-management/

## 🚀 Features
- Real-time hostel display from Django database
- Online booking system
- Admin dashboard for hostel management
- Location filtering: Mungoni, Slaughter, Marine, Lowland, Gate F, Chuka Town, Juverus
- Image upload support
- Responsive design
